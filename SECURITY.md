# Security

A vulnerability in Zetlyn is not an issue. Write to **security@zetlyn.com** instead, with what you
found, how to reproduce it, and the version (`zetlyn --version`). You hear back within three
working days, and the fix is released before anything is said in public. You are named in the
release notes if you want to be.

Only the latest release is fixed: `zetlyn world upgrade`, or the install script again, takes it.

What counts: anything that lets somebody read what a world does not show them, act as somebody
they are not, write to a world, a hub or a source without the right key or grant, or run code on a
machine that serves Zetlyn. A source that publishes wrong data is the source's, not Zetlyn's.
